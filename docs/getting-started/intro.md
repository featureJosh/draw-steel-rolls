# Draw Steel Rolls

**Draw Steel Rolls** adds a cinematic overlay for native Draw Steel test rolls in Foundry VTT v14.

The module does not replace Draw Steel's roll system. It listens for native Draw Steel `test` chat message parts, reads the existing `PowerRoll`, and displays the roll using a visual overlay.

Use Draw Steel's own actor sheet rolls, `/test` enrichers, and test request chat buttons as usual.
